# GRID BREAKER

Python・C++・Javaで経路探索コードを書き、装甲グリッド上の弱点を制限ターン内に破壊するブラウザゲームです。

**PLAY:** <https://akito119.github.io/grid-breaker/>

## 起動

Ubuntuで次を実行します。

```bash
cd /home/akito/project/game
npm start
```

ブラウザで <http://localhost:4173> を開いてください。

2人対戦モードは <http://localhost:4173/duel.html> です。ルーム状態と勝敗判定は、このコマンドを実行しているPC上のNode.jsサーバーが管理します。提出コード自体は安全のためPC上で直接実行せず、サーバーからWandboxへ送信します。

公開版はGitHub Pages上で動作します。ゲーム本体は静的ファイルで構成され、提出コードのコンパイルと実行にはWandbox APIを使用します。

## 2人対戦モード

対戦モードでは、次のフェーズをターンごとに繰り返します。

```text
壁配置 → メソッド構築 → トークン配置 → 解決
```

- 両プレイヤーが同時に壁候補を配置します。盤面を分断する壁候補はサーバーが不採用にします。
- メソッドは確定壁、開始地点、把握済み敵トークンを入力として受け取ります。
- `emit(row, col)` は上下左右の隣接マスへの移動です。壁または盤外を踏むと、その出力を数えたうえでメソッドを終了します。
- 壁衝突前の効果は残り、衝突までの出力数と使用メモリからMPを消費します。
- 同じ処理順のトークン同士を比較し、正規化実行時間が短い側から効果を解決します。
- ルーム情報はメモリ上に保持されるため、サーバーを再起動するとルームは消えます。

### 別PCから参加する

GitHub Pagesを参加画面として使う場合、ルームサーバーにはHTTPSで到達できる公開URLが必要です。Cloudflare Tunnelなどでローカルの4173番ポートを公開し、対戦画面の「ルームサーバーURL」へ発行されたHTTPS URLを入力してください。

例:

```bash
cloudflared tunnel --url http://localhost:4173
```

ルーム作成後に表示される共有URLを相手へ送ります。ルーターのポートを直接開放する構成は推奨しません。

## 遊び方

1. 全弱点の座標とHP、開始位置、歩数上限を確認します。
2. Python・C++・Javaのいずれかで `attack` 関数を編集します。
3. `move(row, col)` を使い、現在位置から上下左右の隣接セルへ移動します。
4. 弱点セルへ進入するたびにダメージを与えます。
5. 最大 `q` ターン以内に全弱点のHPを0にすると勝利です。

クリアすると、ターン数・経路の命中効率・コード長・実行時間とメモリからクリアスコアとランクを計算します。「CONTINUE」でコードを保持したまま次の敵へ進めます。

斜め移動、座標ジャンプ、同じセルでの待機は無効です。ターン終了位置は次のターンの開始位置になります。

## 実行環境

| 言語 | Wandbox環境 |
|---|---|
| Python | CPython 3.13.8 |
| C++ | GCC 13.2.0 / C++20 |
| Java | OpenJDK 21 |

コードはローカルマシンではなく、[Wandbox](https://wandbox.org/) の隔離環境で実行します。インターネット接続が必要です。

## ダメージ計算

```text
B  = ceil((H / q) × 1.20) + 22
Ln = codeBytes / languageCodeBaseline
Tn = clamp(timeMs / languageTimeBaseline, 0.15, 8.0)
Mn = clamp(memoryKB / languageMemoryBaseline, 0.15, 4.0)

damage = max(1, round(B - 12 × Ln - 6 × Tn × Mn))
```

コード長はプレイヤーが編集した部分だけをUTF-8バイト数で計測します。コンパイル時間、通信時間、アニメーション時間は含みません。言語ランタイムの差は言語別基準値で正規化します。

## クリアスコア

- 基本点: 10,000
- ターンボーナス: 残りターンごとに3,000
- 経路ボーナス: 全移動に対する命中回数から最大4,000
- コードボーナス: 言語別に正規化したコード長から最大3,000
- リソースボーナス: 実行時間とメモリ使用量から最大2,500

合計点から `S / A / B / C` ランクを表示します。

## 歩数上限

生存中の全弱点を現在位置から訪問する最短距離 `L*` をビットDPで計算します。生存弱点数を `a` とすると、各ターンの上限は次のとおりです。

```text
S = ceil(1.35 × L*) + a
```

最短距離はマンハッタン距離を使用し、終了地点は自由です。開始位置と弱点が重なる場合は、その弱点へ再進入するための2歩を必要距離として扱います。

## 保存と制約

- 進行中ゲームと各言語のコードはLocal Storageへ自動保存します。
- コンパイルエラー、実行エラー、経路エラーではターンを消費しません。
- Wandboxは第三者サービスであり、障害や同一IPからの利用制限により実行できない場合があります。
- ローカルゲーム向けの設計です。Local Storageを操作できるため、公開ランキング用の不正対策はありません。

UIとブラウザからWandboxを利用する考え方は [Simple C++ Editor](https://tumoiyorozu.github.io/SimpleCppEditor/) を参考にしていますが、実装とデザインは本作独自です。
