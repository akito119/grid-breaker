MISSION BRIEF

装甲グリッドを攻略せよ

0/ 0 TURN

- × - の装甲グリッドに -個の弱点を検出した。 move(row, col) で隣接セルを移動し、全弱点のHPを0にせよ。

座標は0始まり。弱点の位置とHPは公開済み。斜め移動・ジャンプ・待機はできません。

INPUT REFERENCE attack(...) に渡される引数

attack(n, m, start, targets, stepLimit, move)

n
グリッドの行数。row は 0 ... n-1。
m
グリッドの列数。col は 0 ... m-1。
start
このターンの開始座標 (row, col)。前ターンの終了地点を引き継ぐ。
targets
未破壊の弱点一覧。各要素は (row, col, hp)／Target{row, col, hp}。
stepLimit
このターンに許可される移動回数。Pythonでは step_limit。
move
次の隣接セルを記録する関数。Python/C++は move(row, col)、Javaは move.go(row, col)。

開始地点は自動では攻撃しません。move で弱点セルへ入るたびに、その弱点へ1回ダメージを与えます。

HOW TO PLAY

      
コードで敵を走査する

      
    
        
  1. Python・C++・Javaから言語を選びます。
    2. 
        
  2. 公開された開始位置・弱点・歩数上限を使って経路を考えます。
    3. 
        
  3. attack(..., move) の中で move(row, col) を呼び、上下左右の隣接セルへ移動します。
    4. 
        
  4. 提出コードはWandboxの隔離環境で実行されます。結果の座標列をブラウザで再生します。
    5. 
        
  5. 弱点セルへ入るたびに攻撃。ターンの終了位置は次の開始位置になります。
    6. 
        
  6. 短く、速く、省メモリなコードほど1回の命中ダメージが高くなります。
